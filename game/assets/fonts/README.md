# 字体目录 / Fonts

Web 平台没有系统字体，导出前必须在这里放一份中文字体，否则所有中文会显示为方块。

## 一键下载

在项目根目录双击 `download_font.bat`，会尝试下载：

- `NotoSansCJKsc-Regular.otf`（思源黑体 / Noto Sans CJK SC，约 16 MB）

成功后目录里应出现该文件，重新运行游戏即可。

## 手动放置

任选一份支持简体中文的字体（`.otf` 或 `.ttf`）放进本目录即可，文件名不限。程序会：

1. 优先按 `game_state.gd` 中的候选文件名查找；
2. 再扫描本目录，取第一个字体文件；
3. 桌面端若找不到，会回退到系统字体（Windows 上通常是微软雅黑）；
4. Web 端没有回退，必须有字体文件。

推荐字体：

| 字体 | 说明 |
| --- | --- |
| Noto Sans CJK SC / 思源黑体 | 覆盖完整，适合 UI |
| Source Han Sans SC | 与思源黑体同源，字重丰富 |
| LXGW WenKai / 霞鹜文楷 | 更有手写气质，适合剧情界面 |

## 注意

- 字体文件较大，已加入 `.gitignore`，不要提交进仓库。
- 若下载慢，可用迅雷/浏览器手动下载后改名放入。
- 换字体后建议清理 `.godot/imported/` 中旧的字体缓存，或直接在编辑器里重新导入。
- 字体版权遵循各自开源协议（Noto / Source Han 为 SIL OFL）。
