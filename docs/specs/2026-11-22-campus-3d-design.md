## 2. 坐标、比例与方位

- 世界坐标：`+X` 向东，`+Z` 向南，`+Y` 向上，单位 1 = 1 米。
- 场景原点：北门中心 `(0, 0, 0)`；校园主体向 `+Z` 展开。
- 平面图是**上南下北**，建模前整体旋转 180°，使北门位于原点、文博路在北侧。
- 比例校准：以标准 400 米跑道为比例尺（长轴约 180 米），结合文博路—北门—操场距离校正，目标校园范围约 900 m × 900 m。
- 公开卫星影像只作描图参考，不直接打包进成品。高德坐标为 GCJ-02、Esri 为 WGS-84，校准时必须使用同一坐标系，避免偏移。

## 4. 资产与数据规范

### 4.1 Blender 工程

- 使用 Blender 4.x，场景单位 Metric、Scale 1.0。
- 集合划分：`00_ground`、`10_core`、`20_dorms`、`30_sports`、`40_landscape`、`90_helpers`。
- 建筑对象命名：`bldg_<id>`；道路：`road_<id>`；树木：`tree_<id>`。
- 每栋建筑写入自定义属性：`building_id`、`name_zh`、`alias`、`category`、`floors`、`height_m`、`status`、`entrance_x`、`entrance_z`。
- 立面策略：重点建筑用照片贴图；其余用程序化窗带、墙面色块和屋顶材质。
- 低多边形预算：全场景目标 ≤ 250k 三角面；单栋普通建筑 ≤ 2k；图书馆等重点建筑 ≤ 8k。

### 4.2 导出管线

1. Blender 描图与挤出体量。
2. 赋予材质与命名，写入自定义属性。
3. 运行 `blender/scripts/export_gltf.py` 导出 `web/public/models/campus.glb`。
4. 同一脚本从自定义属性生成 `web/src/data/buildings.json`，保证模型与信息卡 ID 一致。
5. 网页加载 GLB，叠加 `campus.json` 中的道路、水体、POI、出生点和导览路线。

**v0.1 环境适配**：本机未检测到 Blender，且 npm 安装受权限限制。v0.1 先由网页端读取同一份 `buildings.json` 程序化生成体块，保证免安装即可运行；`blender/build_campus.py` 作为源工程生成器交付，安装 Blender 后运行即可生成 `.blend` 和 `campus.glb`，再切换到 GLB 加载。

### 4.3 数据文件

`buildings.json` 单栋示例：

```json
{
  "id": "library",
  "name": "图书馆",
  "alias": ["图文信息中心"],
  "category": "library",
  "status": "built",
  "floors": 5,
  "height_m": 28,
  "centroid": [0, 120],
  "entrance": [0, 108],
  "description": "校园主轴线尽端的标志性建筑，正对文翰广场。",
  "photo": "photos/library.jpg"
}
```

`campus.json` 保存：校园边界、道路中心线、水体轮廓、广场、体育场地、POI、出生点、导览路线。

## 5. Web 交互

- 技术栈：静态 HTML + ES Module + Three.js（CDN import map），免构建；原生 DOM/CSS UI，不引入 React。Node 24 内置测试运行器做数据与几何单测。
- 三种视角：
  - 步行：WASD/方向键移动，鼠标看向四周，1.7 m 视高，建筑与树木碰撞。
  - 飞行：WASD + Q/E 升降，Shift 加速，无碰撞，适合快速查看全校区。
  - 鸟瞰：轨道控制，拖拽旋转、滚轮缩放、右键平移。
- 小地图：北向上，显示校园轮廓、建筑轮廓、POI 和玩家朝向；点击/轻触传送。
- 信息卡：点击建筑弹出名称、别名、类别、层数、简介和照片；提供“传送到入口”。
- 昼夜：白天/黄昏/夜晚三档或滑杆；夜晚点亮窗户与路灯，阴影降级。
- 移动端：默认鸟瞰 + 点击信息卡；步行模式提供虚拟摇杆与拖拽视角；关闭高质量阴影，像素比上限 1.5。
- 性能：桌面 1080p 目标 60fps；中端手机 30fps；GLB ≤ 25 MB，首屏可交互 ≤ 10 MB；Draco 压缩、树木实例化、静态几何合并、绘制调用 ≤ 150。

## 7. 验收标准

- 从北门出发，可步行到教学主楼、图书馆、文脉湖、操场和宿舍区，不穿模、不掉出地面、不被卡死。
- 20 栋以上建筑可在场景中识别，并可点击查看信息卡。
- 小地图位置与实际位置误差 ≤ 5 m，点击建筑可传送到入口。
- 步行/飞行/鸟瞰三种模式可切换，昼夜可切换。
- 桌面端 1080p 目标 60fps；手机简化模式可正常游览。
- 控制台无报错；刷新后能从北门重新开始。

## 9. 风险与待补资料

- 平面图是示意图，建筑轮廓与道路存在约 5–10% 误差；航拍为 720p 且无 GPS，无法做高精度摄影测量。
- 规划中/在建建筑的实际完成度需用航拍核对；与平面图冲突时以现状为准。
- 需要补充：原始平面图或 CAD、重点建筑层数、各建筑正面照片、10–20 张航拍关键帧。
- 建筑常用别名待确认：教学 1#/2# 与博文楼/笃学楼的对应关系、第一/第二餐厅与齐风坊/鲁味坊的对应关系。
- 本机未检测到 Blender，且 npm 安装受权限限制；v0.1 采用免安装静态网页 + 程序化体块，Blender 生成脚本作为源工程交付，安装 Blender 后可补 `.blend` 与 `.glb`。
- 当前会话的 Bash 写入受限；项目文件可用编辑器工具创建，但依赖安装、Blender 导出等需要额外授权。
- 发布方式待定：Qoder Sites、GitHub Pages 或学校服务器。
